# Restaurant Analysis using SQL

## Overview
This project focuses on analyzing restaurant data using SQL to extract meaningful insights and solve business-oriented analytical problems.

## SQL Concepts Used
- Normal SQL Queries
- Subqueries
- Window Functions
- Aggregate Functions
- GROUP BY and HAVING
- ORDER BY and Filtering
- Joins

## Analysis Performed
- Analyzed restaurant performance and ratings
- Compared restaurants using ranking and window functions
- Used subqueries to solve complex analytical problems
- Applied aggregate functions to derive business insights
- Performed data filtering, grouping, and sorting

## Objective
To strengthen SQL skills by solving real-world restaurant analysis problems and applying advanced SQL concepts for data-driven insights.
